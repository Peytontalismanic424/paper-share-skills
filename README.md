# 📦 paper-share-skills - From PDF to Bilibili in One Go

## 🚀 What This Tool Does
This application transforms academic PDF papers into a complete Bilibili video presentation. It handles the entire pipeline: extracting content from a PDF, generating a LaTeX Beamer slide deck, producing a narrated MP4 video, and preparing it for upload to Bilibili. No coding or video editing skills are required.

## 🎬 What Happens When You Run It
The application performs these automated steps:
1. **Reads your PDF paper** – Supports most academic papers from arXiv
2. **Creates Beamer slides** – Professional-tier LaTeX slides with proper formatting
3. **Generates narration audio** – Uses AI text-to-speech to read your paper
4. **Combines slides and audio** – Produces an MP4 video
5. **Prepares Bilibili upload** – Formats everything for your Bilibili channel

## ⚙️ How to Use the Program

### Initial Setup
1. Open the program to see the main dashboard
2. Grant file access permission if asked
3. The interface is a simple step-by-step wizard

### Importing Your PDF
- Click the "Upload PDF" button to open your paper file
- The program works with any PDF from arXiv or similar sources
- Processing time depends on PDF length (typically 2-5 minutes)

### Previewing Slides
- After PDF processing, the slide preview will appear
- You can adjust slide templates using the "Themes" dropdown
- Click "Generate Slides" to create the final presentation

### Adding Narration
- Click "Add Voiceover" to activate text-to-speech
- Choose between male/female voices and languages
- The program reads slide content and creates audio

### Creating Video
- Click "Render Video" to combine slides with audio
- Wait for the progress bar to complete (10-30 minutes for a 10-page paper)
- Your MP4 file will appear in the project folder

### Upload to Bilibili
- Click "Upload to Bilibili" and log in to your account
- Fill in title, description, and tags for your video
- Set privacy settings and click "Publish"
